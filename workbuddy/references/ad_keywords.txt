# ⚠️ 撞车词规则（2026-09-13 事故后强化，加词前必读）
#  词表是**子串匹配**，只写一个泛义词就会把正常内容打上广告标记。
#  已踩坑：「广告」命中「招聘广告」「广告登出」；「工商」命中「工商银行」。
#  所以：
#    1. 泛义名词/动词（广告、工商、推广、赞助、秒杀、甲方）**一律不写裸词**，
#       必须写成限定短语（本期广告 / 工商合作 / 商业推广 …）
#    2. 品牌名与生活常用词、人名、书名、机构名撞车时，写全称或产品名
#       （不写「夸克」写「夸克App」；不写「苏菲」写「苏菲卫生巾」）
#    3. 靠限定短语仍消解不掉的，写进第五节的排除段（前缀 ! ）
