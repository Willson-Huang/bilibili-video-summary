# B站 AI 字幕机制验证 —— 实测报告

> 日期：2026-09-19
> 性质：实证测试（3 个被试 · 4 项测试 · 接口层 + 双通路对照）
> 结论指向：订正 v2.5.2 对 `ai-zh` 的机制归因（**其结论「专名不可信」仍成立，被推翻的只是错因**）

**一句话**：`ai-zh` 的「回译」帽子可以摘了 —— 它是原生中文 ASR，正文能用、专名不能信；而长片没字幕是时长规律，不是付费墙。

---

## 一、测试范围

### 1.1 起点与待验假设

旧文档把 B站 AI 中文字幕轨 `ai-zh` 描述为「**经中文 → 英文 → 中文回译**」的产物，并据此规定：

- 专名偏差大（回译错译 + 同音替代）
- 不可作任何基准
- 专名密集内容一律 `--force-asr` 强制本地转写

**本次测试要回答的就是这条归因是否成立**，以及在此之上量化 `ai-zh` 的真实准确度、并核清「长片到底有没有字幕可用」。

### 1.2 被试（3 个）

| # | BV | 标题 | UP主 | 时长 | 充电专属 | 字幕轨 |
|---|---|---|---|---|---|---|
| V1 | `BV16w41187fx` | 迷 失 东 京 | 食贫道 | 2:08:55（7735s） | 是 | **0 条** |
| V2 | `BV1NGHGzJEfx` | 首 尔 夏 天 | 食贫道 | 3:17:25（11845s） | 是 | **0 条** |
| V3 | `BV17gtEziEE7` | 5500韩元在韩国女校食堂能吃到什么？没有草料，但也没有肉 | 食贫道 | 16:19（979s） | 否 | **6 条** |

选 V3 作 `ai-zh` 机制与准确度的主被试，理由有三：① 短（979s，本地转写可全量跑）；② 有 6 条字幕轨可做互相对照；③ **画面里烧了 UP主 自制的人工中文字幕**，可作真值锚点。

### 1.3 测试方法（三条互相独立的通路）

| 通路 | 用途 | 实现 |
|---|---|---|
| ① 接口层核查 | 判字幕轨有无、判付费墙是否屏蔽 | `x/web-interface/view` + `player/wbi/v2` + `playurl`（含 `Range` 试取） |
| ② 画面内嵌字幕 | 语义级真值（UP主 人工制作） | `x/player/videoshot` 精灵图 → PyAV 解 ndarray → numpy 裁切放大 |
| ③ 本地 ASR | 第二把独立尺子 | `bili_asr.py --force-asr --engine whisper --model large-v3`（978.4s） |

### 1.4 明确不在本次范围内

- 未测 LLM 后纠正环节
- 未测外语占比高的段落（如多语种混排长片）
- 未在「中文人名密集」类内容上复现（仅 1 个中文口播样本）
- V1 / V2 未做准确度测试（无字幕轨，无从对照）

### 1.5 合规边界（本测试实际做了什么）

接口层探测的目的是**判定字幕轨有无**，不涉及内容分发：

- `playurl` 的 `Range: bytes=0-2047` 试取**仅验证接口可达性**，未落盘完整音轨、未分发任何内容
- 账号权限范围内的检测结果不构成绕过行为；本工具与本文档均不提供下载付费 / 充电专属内容的能力或指引
- 复现请仅针对你本人账号有权查看的内容，遵守 [README 注意事项](../README.md#注意事项)

## 二、执行结果

### 2.1 T1：字幕轨可得性（V1 / V2）

| 项 | V1 迷失东京 | V2 首尔夏天 |
|---|---|---|
| `player/wbi/v2` → `subtitle.subtitles` | `[]` | `[]` |
| `need_login_subtitle` | false | false |
| `allow_submit` | false | false |
| `is_upower_exclusive` | true | true |
| `playurl` `code` | 0 | 0 |
| `dash.duration` vs 视频总长 | 7735 == 7735 ✅ | 11845 == 11845 ✅ |
| `Range: bytes=0-2047` | HTTP 206 ✅ | HTTP 206 ✅（总长 142.6 MB） |

**结论：两片均无任何字幕轨；接口层可达性正常。**

判据不止「列表为空」——**做了付费墙对照**：同季 9 集里 6 集返回 `ai-zh`，其中**同为充电专属**的 Reaction 集（203min）三语字幕齐全 ⇒ 排除「付费墙屏蔽字幕」这一解释。

### 2.2 T2：同 UP主 的字幕可得性规律

把食贫道「人间喜剧·韩国篇」全 7 集 + 日本篇 2 集一次查完：

| 时长 | 充电专属 | 字幕轨 |
|---|---|---|
| 16 / 12 / 15 min（韩国篇） | 否 | **6 轨**：`ai-zh` `ai-en` `ai-ja` `ai-es` `ai-ar` `ai-pt` |
| 20 min（韩国篇·幕后特辑） | **是** | **6 轨**（同一组） |
| 12 min / 1 min（日本篇） | 否 | 6 轨 |
| 50 min 跟拍外卖员 / 97 min 卧底30天 | 否 | **`[]`** |
| 128 min 迷失东京 / 172 min 战后八十年 / **197 min 首尔夏天** | 是 | **`[]`** |

**规律：字幕有无与「充电专属」无关，与时长强相关 —— ≤20min 短片带 6 语 AI 字幕，≥50min 长片一律无轨（免费/充电皆然，实测 5 例全空）。**

附带认知更新：**B站 AI 字幕早已不止 `ai-zh` 一种**，该 UP主 短片一次给足 zh/en/ja/es/ar/pt 六轨。

> 实用推论：≥50min 的视频直接按「无字幕、必走 ASR」排期，不必浪费接口调用去探测。

### 2.3 T3：`ai-zh` 的生成机制（V3，核心测试）

**结论：`ai-zh` 是原声中文 ASR 轨，不是「中→英→中」回译产物。** 三条判据：

| # | 证据 | 数据 |
|---|---|---|
| 1 | `ai-zh` 检出**中文同音 ASR 错误** | `草料哥 → 长廖哥`（1 处）、`草料哥为我们提供 → 从来为我提供`（1 处）、`当代艺术 → 当代一直`（1 处）。**英译中不可能产生这类错误**，它们是中文语音识别的指纹 |
| 2 | 英文轨在中文轨错处反而是对的 | `ai-zh` 写「当代一直」，`ai-en` 写 `contemporary art` |
| 3 | 六轨共用同一套语段边界 | en/ja/es/ar/pt **各 412 条且时间戳逐条相同**；zh 439 条，但 **92.3% 的 zh 起点精确落在 en 起点上、100% 落在 en 区间内** |

判据 1 单独即可定案；判据 2 说明生成链上存在语义纠错能力（无论六轨同源还是翻译环节带纠正），**但两条路都不支持「zh 由 en 回译而来」**——回译不可能丢掉 en 的正确性、又凭空生出中文同音错。

### 2.4 T4：`ai-zh` 的准确度（V3，两把尺子）

#### 尺子 A —— 画面内嵌人工字幕（真值锚点）

12 个抽样点中 8 点有字幕，**8/8 内容吻合**：

| 画面字幕（UP主 人工） | ai-zh | 判定 |
|---|---|---|
| 草料哥帮了很多忙 | 这草料哥帮了很多忙 | ✅ 逐字 |
| ……专门来给你写（写）简历…… | 就专门来给你写写简历那种啊 | ✅ 逐字 |
| 中国人拍我们拍不好之类 | 中国人拍我们食堂不好之类的 | ✅ 同句（画面省「食堂」） |
| 8点进图书馆 | 八点进图书馆 | ✅ 同句（数字写法） |
| 但是这么筛选出来的人是真厉害 | 他这么筛选出来的人是真厉害 | ✅ 同句（省主语） |
| （收据道具）5500韩元 | 也就27块五一个人 | ✅ 换算正确 |

#### 尺子 B —— 本地 whisper large-v3 独立转写

- 33 个 30s 窗口逐窗比对，**内容基本一致**（如 02:30 窗口两路同为「5500韩／27块五…溜着边走…放一下」）
- raw 字符相似度仅 **0.516**，原因是**两路时间对齐有 10–20s 漂移**，不是内容差异

> ⚠️ 方法论警告：直接拿窗口相似度当准确度指标会被这个漂移严重带偏。

#### 实测到的真错，3 类

| 类型 | 实例 | 说明 |
|---|---|---|
| 专名同音 | `草料哥 → 长廖哥`、`草料哥为我们提供 → 从来为我提供` | **同一专名片内写错 2 次** |
| 词义同音 | `艺术 → 一直` | 同音但词典义合法，最危险的一类 |
| **双引擎共同错** | UP主 品牌「**大宝荐**」→ ai-zh 写「大保健」、large-v3 写「大宝剑」 | **两路都错**，正确写法只能从同季集名反查 |

**准确度分层**：正文级可信（语义吻合 8/8、数字换算正确、与本地 ASR 内容一致）；**专名级不稳**（片内重复错、且存在双引擎共同错）。

## 三、发现的问题

### 3.1 被推翻的既有归因（优先级最高）

| 项 | 旧表述 | 实测结论 |
|---|---|---|
| `ai-zh` 生成机制 | 「经中文 → 英文 → 中文回译」 | **不成立**：它是原声中文 ASR 轨，错因是中文同音误识 |
| 专名偏差的原因 | 「回译错译 + 同音替代」 | 只有同音误识，无回译错译机制 |

**对下游结论的影响**：此前 `LLM纠正AI字幕-*` 系列的实验数据与结论（原文专名正确率 30.4% / 85.0% → 纠正后 93.9% / 100.0%，LLM 纠错可行）**仍然成立且有效**——被推翻的只是**归因**，不是结果。但引用时需订正前提描述，否则读者会按错误机制推理。

> 一个连带推论：既然 `ai-zh` 与本地 ASR 是**两路独立识别、错点不同**，那「AI 字幕 + LLM 纠正」之所以能超过本地 Nano（93.9% vs 70.5%），可能不只是「纠正」起了作用，而是**两路信息本就互补**。这一点未测，列为待验。

### 3.2 工具 / 流程缺陷（3 条，均已写入 SKILL）

| # | 问题 | 实测表现 | 影响 |
|---|---|---|---|
| 1 | `videoshot` 的 `index` 时间戳与字幕时间轴有**约 +5s 偏移** | 第一轮比对把 8/8 的吻合误判成「3 处错位」 | 会把真值锚点用错，得出反向结论 |
| 2 | 同 `index` 字段**会间歇返回空数组** | 首次调用返回 187 项，复调返回 0 项 | 抽样脚本直接崩；需重试 2–3 次或按 `时长/(张数×100)` 线性推算 |
| 3 | **默认 `--prompt` 会泄漏成正文** | 素材包首段即 `[00:00:00] 请使用正确的中文标点符号。` | 每份素材包开头多一条伪造正文，且会被误当真实内容送进纪要 |

> 第 3 条现状：`--prompt` 默认值（`以下是普通话的中文内容，包含专业术语。请使用正确的中文标点符号。`）**当前仍未固化修改**，需要时显式传 `--prompt ""` 规避。

### 3.3 未决与存疑

1. **本机无 ffmpeg、无 PIL** —— 已用 PyAV + numpy 绕过（`av.VideoFrame.from_ndarray` + `add_stream('png')` + `image2` muxer），但这是绕行方案，未纳入依赖清单。
2. **`ai-zh` 机制仅在 1 个中文口播样本上验证**（439 cue）。外语占比高的样本未测，不能外推。
3. **`--prompt ""` 的实际效果未复验**：仅从原理判断清空即消失，未重跑确认。

## 四、结论

### 4.1 直接结论

1. **`ai-zh` 不是英文回译**，就是原声中文 ASR 轨。旧版归因错误，已订正。
2. **准确度分两层**：正文级可信（画面人工字幕 8/8 语义吻合、数字换算正确、与本地 ASR 内容一致）；**专名级不稳**（同一专名片内 2 次写错，且存在双引擎共同错）。
3. **长片没字幕不是「充电专属」造成的，是时长**。≥50min 一律按「无字幕、必走 ASR」预估。
4. **两路 ASR 互补而非替代**：互相对照能定位错处，单靠任一路都会漏。

### 4.2 对文档的处置

| 改动 | 内容 |
|---|---|
| `ai-zh` 判据表 | 机制订正 + 附 5 条实测证据 |
| 引擎分流表（2 行） | 理由由「回译不可信」改为「两路独立识别、错点不同」 |
| 双源做法 / 路由逻辑表 / `engine` 字段 / `--force-asr` 参数表 | 同上口径统一 |
| 语言参数节 | 订正 whisper 侧 `--lang` **不做 auto 映射**（默认 `zh` 即强制中文），并写明 `--prompt` 默认值的中文先验效应 |
| 新增「多语种混合音频怎么处理」节 | 三项前置核查表 + 内嵌硬字幕查法 + 三条处理路径 + Nano 不适用说明 |
| 新增「同 UP主 规律」小节 | 时长判据 + 6 语种清单 |
| 新增「三个实测坑」 | `videoshot` 偏移 / `index` 空值 / `--prompt` 泄漏 / 画面字幕只能作语义级基准 |

### 4.3 建议下一步（按性价比排序）

1. **复验 `--prompt ""`**：重跑 V3 首段，确认泄漏消失（约 3 分钟，成本最低）。
2. **补一个外语占比高的样本**：验证「两路互补」在外语段是否仍成立（若成立，长片 ASR 可用双源交叉定错）。
3. **订正前序实验的前提描述**：在 `LLM纠正AI字幕-*` 两文件中加一行归因订正，保留原数据。
4. **把 `--prompt ""` 固化进脚本默认值**（需评估对既有中文场景的影响后再动）。
