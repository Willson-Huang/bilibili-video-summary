# 知识库条目模板

用于把视频/播客/访谈内容整理成可长期检索、可回溯、可验证的知识库条目。
**这是本 Skill 的唯一输出格式**，所有视频都按这套结构产出。

命名：`<发布日>_<完整标题>_<UP主>_纪要.md`，发布日取内容产生日而非处理日；标题原文照抄，只剔除 Windows 非法字符，全角标点保留。

---

## frontmatter

```yaml
---
title: <标题>
date: YYYY-MM-DD
type: 转写·访谈
source: <来源平台 + 编号>
source_url: <链接>
duration: <时长>
speakers: <主讲人/嘉宾>
confidence: 高 / 中高 / 中 / 低，后接一句话理由（如"中（UP 主自述分析，第三方数据未给出报告全称）"）
tags: [src/<UP主·公众号·栏目>, topic/<词表桶>, entity/<已建页实体>]
keywords: [<页内关键词，原样保留，数量不限>]
entities: [实体1, 实体2, ...]
created: YYYY-MM-DD
review_by: YYYY-MM
status: 待复核
---
```

`review_by` 按内容中最远的待验证判断设定，通常 3–6 个月。

**tags / keywords / entities 是检索命中的关键，必须认真填**：

| 字段 | 填什么 | 粒度指引 |
|---|---|---|
| `tags` | **分类维度**（用于导航），不是关键词 | 只放带命名空间前缀的桶名，通常 2–5 个：`src/` 来源（UP主 · 公众号 · 系列栏目）、`topic/` 主题（**封闭词表 17 桶**：AI与Agent · AI办公 · 大模型与算力 · AI与社会 · AI硬件与终端 · 中国经济与财政 · 城市与区域 · 产业与企业 · 政策与规划 · 历史与人文 · 社会与性别 · 内容创作 · 方法论与思维 · 生命与哲学 · 国际地缘 · 中国台湾地区 · 国家治理）、`entity/` 已建页的实体。⚠️ **不带前缀的标签一律无效**，不得自创桶名 |
| `keywords` | **页内关键词**（只用于检索与回溯，不导航） | 数量不限。半年后想找这条时脑子里冒出的那几个词全写这里——具体词（卖官、铸劣币）、长尾专名（Siri、西芒杜）、泛义词（人物、合理）都收。**这条不能省，缺了会被判不合规** |
| `entities` | 实体名单，回答"这条提到了谁/什么" | 8–12 个。人物、组织、产品、模型、地名、专有制度名。**写全名，必要时带别名**——搜"交子"要能命中，搜"腓力四世"也要能命中，别只写"法王" |
| `title` | 可读的一句话标题，不照抄视频标题 | 概括内容主张，而非复述标题。视频标题带营销味时尤其要改 |
| `type` | 内容类型，**封闭枚举、不得自创** | 转写类：`转写·访谈`（播客/对谈/圆桌/专访）· `转写·科普`（知识科普/课堂实录/测评）· `转写·评论`（评论/观点/解说/人物商业史）· `转写·教程`（教程/方法/实测演示）；非转写：`公众号` · `政策原文`。更细的描述写选填字段 `subtype`，不要塞进 `type` |
| `confidence` | 档位 + 一句话理由 | 档位只能取 **高 / 中高 / 中 / 低**。理由是必填项，不写理由等于没填；定档依据是**发布来源 + 体裁**，不是你对内容的印象 |

判断标准：半年后想找这条时，你脑子里最先冒出来的那几个词，就是 `keywords`；能按它们整批调出来的类目，才是 `tags`。

## 使用规则

1. **只增不减**：对已有条目做增强时，原有章节、时间戳、表格、金句说明文字逐项保留，新增要素以独立章节追加。
2. **写完必校验**：运行 `scripts/verify_coverage.py <原文件> <新文件>`，时间戳与章节标题缺失数必须为 0，新文件体积必须大于原文件。初次生成无需校验，重写和增强必做。
3. **反共识观点单列**：不埋在正文里。这类内容半年后最容易遗忘，也最有复用价值。
4. **待验证清单必填**：节目/访谈中的判断都有时效性。不标验证时点，就会永远挂在"待验证"状态。
5. **术语表收录领域黑话**：脱离语境半年后，缩写和行话是最大的理解障碍。
6. **广告内容零容忍**：带货口播（品牌名、优惠券、小黄车、下方链接等）一律不写入任何章节——不进核心结论、不进内容要点、不进金句、不进反共识观点。素材包里带 `[广告?]` 标记的段落直接跳过。
7. **公开发布须附版权声明**：条目含他人作品的摘录与转写（要点、金句）。对外公开时必须附视频链接、版权归属（归 UP主/权利人所有）说明，并提供删除通道（如 Issue）；本地个人知识库存档无需。付费/大会员内容不得用于公开条目。

---

## 广告段落处理

素材包中带 `[广告?]` 前缀的段落，以及末尾「疑似广告段落」表格列出的区间，生成条目时整段跳过。

判断标准不止关键词表：只要内容实质是商品推介、引流或优惠引导，即使未命中词表也归入广告剔除。

剔除后无需在条目中说明"此处有广告"，直接当它不存在。仅在「信息完整性」的转写覆盖里如实记录总时长即可。
